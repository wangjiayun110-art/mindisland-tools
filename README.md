# MindIsland Tools

Small free web tools from [心屿 MindIsland](https://www.790221.xyz) — each one is a single self-contained page you can open in a browser. No build step, no server needed.

## Tools

| Tool | File | Live page |
| --- | --- | --- |
| 抽情绪卡 — free draw, no sign-up: 24 emotion cards, each with one line about how it feels and one small thing to try, collection album saved in the browser | `emotion-card.html` | https://www.790221.xyz/emotion-card.html |
| 进口化妆品批号查询 — check a batch code for 12 brands and estimate the production date | `cosmetics-batch-check.html` | https://www.790221.xyz/cosmetics-batch-check.html |
| 各省历年高考录取分数线查询 — 31 provinces × 2021–2025 | `gaokao-scores.html` | https://www.790221.xyz/gaokao-scores.html |

The pages share `tailwind-compiled.css` at the repo root, so keep it next to the HTML files. The cards are general suggestions, not a diagnosis.
